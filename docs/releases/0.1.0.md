# Battle Sim Kotlin SDK 0.1.0

Initial Kotlin/JVM port of the protocol 3.x Python SDK, based on upstream revision
816fa9baba75c7294561a6f111aa2735f4bbdd01. Requires Java 17+ and Kotlin 2.4.20+ for Kotlin consumers.

Includes typed protocol/configuration models, all twelve powerups, multi-round WebSocket
sessions, cancellable asynchronous execution, bounded lobby reconnection, diagnostics,
Python-compatible recording/replay, and the full tactical toolkit. Source, examples,
Maven wrapper, API guide, and migration notes are included in the repository.

Validation: 45 passing tests, including 240 Python-generated reference cases, actual
loopback WebSocket tests, and two Kotlin bots completing two rounds against the local Rust
server with configuration changes, powerups, telemetry, and recording/replay.

## Downloads

- `naval-sdk-kotlin-0.1.0-all.jar`: executable patrol bot and bundled runtime dependencies.
- `naval-sdk-kotlin-0.1.0.jar`: library JAR; dependencies are declared in the POM.
- `naval-sdk-kotlin-0.1.0-sources.jar`: Kotlin library sources.
- `naval-sdk-kotlin-0.1.0.pom`: Maven dependency metadata.
- `SHA256SUMS`: checksums for the four artifacts.

```sh
java -jar naval-sdk-kotlin-0.1.0-all.jar --help
java -jar naval-sdk-kotlin-0.1.0-all.jar --env-file /path/to/participant.env
```

Use `./mvnw install` from a checkout to make the library available to local Maven/Gradle
projects. This release is distributed on GitHub; it is not a Maven Central publication.
